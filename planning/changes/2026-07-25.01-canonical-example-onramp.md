# Design: Canonical minimal-DI example (grpc rollout)

## Summary

Ship a canonical, runnable example in `modern-di-grpc`: a minimal `examples/`
app wiring one `Settings` (APP scope) and one `Greeter` (REQUEST scope) into a
`SayHello` servicer method via the real `@inject` + `FromDI` idiom, an
in-process smoke test that proves it runs and asserts the real greeting, and
the README `Usage example:` line. This rolls out the pattern locked by the
[faststream pilot](https://github.com/modern-python/modern-di-faststream/blob/main/planning/changes/2026-07-24.01-canonical-example-onramp.md)
to this repo.

## Motivation

The blessed-ready on-ramp audit found `modern-di-grpc` at D2=1 / D6=1: a
complete inline README example but no dedicated, linked canonical example, so
neither the `Usage example:` line (D6) nor a D2=2 score is reachable. The
faststream pilot locked the reusable shape; this change applies it here.

## Design

**The example** — `examples/app.py` (+ `examples/__init__.py`): the smallest
runnable grpc service that demonstrates the recommended wiring, matching the
README snippet's names (`Settings`, `Greeter`, `AppGroup`, `GreeterService`,
`SayHello`) as a complete, testable program:

- `Settings` — `providers.Factory(Settings, scope=Scope.APP, cache=True)`.
- `Greeter` — `providers.Factory(Greeter, scope=Scope.REQUEST)`, depends on
  `Settings` by type (auto-injected).
- `GreeterService.SayHello` — `@inject`-decorated, takes `Greeter` via
  `typing.Annotated[Greeter, FromDI(Greeter)]` (resolve by type), matching the
  repo's fixed `(request, context)` servicer signature.
- `build_server(port=...)` — wires the container (`container.open()`, since
  grpc gives the adapter no root-lifecycle hook), builds a `grpc.server(...)`
  with `DIInterceptor(container)`, registers `GreeterService`, starts
  listening, and returns `(server, bound_port, container)`. Both the real-run
  guard and the smoke test call this one function, so the wiring under test is
  exactly the wiring that runs for real.
- `if __name__ == "__main__":` — the only genuinely unreachable part (blocks
  on `server.wait_for_termination()`); marked `# pragma: no cover` on the
  `if` line, which coverage.py excludes as a whole clause. A `# run: python -m
  examples.app` header states the real-run command.

Proto stubs are reused from `tests/protos/greeter_pb2(_grpc)`, generated from
the existing `greeter.proto` — no new proto is introduced, matching the
`SayHello` RPC the README already documents.

**Smoke test** — `tests/test_example.py`: imports `build_server` from the
example, calls it (ephemeral `127.0.0.1:0` port), opens a real
`grpc.insecure_channel` to the bound port via the existing generated
`GreeterStub`, calls `SayHello`, and asserts the real greeting
(`"Hello, world!"`) — the same in-process-server idiom `tests/conftest.py` and
`tests/test_sync.py` already use, with no external server or mocks.

**Coverage** — none excluded. Calling `build_server()` from the smoke test
exercises every module-level definition and the whole function body, so
`examples/app.py` is covered to 100% under the existing `--cov-fail-under=100`
gate save the one `# pragma: no cover` line noted above.

**README** — insert `Usage example: [examples/](./examples)` directly under
the `Full guide` line, before `## Installation`, matching the faststream
pilot's placement. The existing inline `## Usage` snippet stays — the example
is its fuller, runnable form and uses the same names.

No `modern_di_grpc/` source changes, so no `architecture/` promotion — this
adds documentation-grade example + test, not a capability change.

## Non-goals

- Editing the inline README snippet or any integration behavior.
- A realistic/multi-service starter — minimal DI demo only.
- New runtime dependencies — the example uses only `grpcio` + `modern-di`,
  already present, and the test-only `tests/protos` stubs.

## Testing

- `just test-ci` green: the smoke test covers `examples/app.py` to 100% (one
  `# pragma: no cover` line for the unreachable real-run block) and asserts a
  real greeting resolved through the live `DIInterceptor` + container.
- `just lint-ci` green (ruff/ty/eof/format over the new files).
- `just check-planning` green (this bundle validates).
- Manual sanity: `python -m examples.app` starts and serves until Ctrl+C
  (documented, not a CI gate).

## Risk

- **Example rot** (low x low) — mitigated structurally: the example is
  measured (no coverage exclusion beyond the one unreachable line) and the
  smoke test executes it every CI run.
- **Example drifts from the README snippet** (low x low) — they share the same
  names and shape; keep the example the runnable superset of the snippet.
